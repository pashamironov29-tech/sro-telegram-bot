# Чат-бот реестра и сервисов СРО — что умеет и зачем

**Для кого этот документ:** для сотрудников, контроллёров и членов СРО — простым языком.  
**Версия бота:** 2026-07-26-v95  
**Работает:** 24/7 в Telegram, на телефоне и ПК.

---

## Зачем нужен бот

На 15 сайтах СРО — реестры, бланки, правила. Искать вручную долго. Бот — **одна точка входа**: набрал ИНН — получил карточку, бланки, план проверки, ответы на частые вопросы. Без ожидания на линии, без переключения между пятнадцатью сайтами.

**Бот не заменяет юриста.** Он ведёт к официальным материалам и снимает рутину.

## Главные функции

### 1. 🔍 Поиск организации по ИНН или названию

- Вводишь **ИНН** (или часть названия) — бот ищет по реестрам **15 СРО** (~18 000 организаций).
- Показывает **карточку**: название, статус («Член СРО» / «Исключен»), дата регистрации, страховая, руководитель.
- Если организация в **нескольких СРО** (например, строительное + проектное) — кнопки выбора.
- Если в плане есть проверка — показывает **месяц** из годового плана.

**Почему удобно для контроллёра:** не надо открывать 15 сайтов — одна карточка со всеми членствами и проверками.

---

### 2. 📋 Бланки для проверки (7 документов)

После поиска по ИНН → выбор СРО → **кнопки скачивания**:

1. Информационный лист
2. Заявление на проверку
3. Доверенность
4. Акт проверки
5. Заявление о внесении изменений
6. Акт об отказе
7. Уведомление о проверке

**Важно:** комплект бланков — **именно того СРО**, которое выбрано. ОСОТ получает бланки с nup-sro.ru, ОГПО — с sroogpo.ru, а не общий шаблон ОГПС.

**Автозаполнение (информационный лист + заявление на проверку):** название, ИНН, юр. адрес, рег. номер, ФИО руководителя — подставляются из реестра. Нужно только проверить и дописать то, чего нет в публичных данных.

---

### 3. 💬 ИИ-помощник

Задаёшь вопрос текстом — бот отвечает с приоритетом **официальных источников** (сайты СРО, законы, FAQ). Если точного ответа нет — даёт ссылку на сайт и контакты.

ИИ **учитывает контекст**: если ты выбрал проектное СРО — не путает с требованиями для строителей.

---

### 4. ❓ FAQ — короткие ответы на частые вопросы

Бот знает ответы на **~50 типовых вопросов**. Примеры:

**Для вступающих:**
- Как вступить в СРО?
- Какие документы нужны?
- Размеры взносов (КФ) — разбивка по уровням ответственности
- Сроки вступления
- Требования к специалистам
- «Строительство для себя — нужно ли СРО?»

**Для действующих членов:**
- Как получить выписку из реестра?
- Возврат взноса из компфонда (нет, нельзя — и почему)
- Изменения в реестре — порядок
- Расписание проверок (план по месяцам)
- Устранение нарушений

**Про НОК и специалистов:**
- Документы для НРС
- Правила сдачи НОК
- Подготовка к НОК
- Кураторы НРС

**Юридические / общие:**
- Когда исключают из СРО?
- Выплаты из компенсационного фонда
- Можно ли учесть взносы в расходах?
- Нужно ли уведомлять налоговую о членстве?
- Нужен ли допуск, если строите сами?
- Какие меры дисциплинарного воздействия бывают?

Ответы — не «от себя», а из официальных источников с кнопкой-ссылкой на сайт.

## Технические детали (кратко)

- **Реестр:** кэш `reestr_cache.json` (~18 000 организаций, 15 СРО), обновление через `reestr_sync.py`.
- **Планы проверок:** `sro files/plany/*.docx` — загружаются при старте.
- **Бланки:** `sro files/blanki/` — по папкам на каждое СРО, файлы с официальных сайтов.
- **ИИ:** Groq API, приоритет FAQ и ссылок srogen.ru.
- **Автозаполнение бланков:** информационный лист + заявление на проверку — все 15 СРО.
- **Запуск:** `START_BOT.bat` или `py bot_FINAL_GOLD.py` (нужен Python 3.12+).

---

## Что **не** делает бот

- Не даёт юридических консультаций — только ссылки на официальные документы.
- Не удаляет и не редактирует данные реестра — только показывает.
- Не автозаполняет все поля бланков — только публичные данные из реестра + дисклеймер «проверьте перед подачей».
- Не заменяет сайт — дополняет его как быстрый интерфейс.
