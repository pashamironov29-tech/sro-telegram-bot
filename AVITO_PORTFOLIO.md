# Авито — портфолио (что нажимать и что вставлять)

Дата: 2026-08-09.

На экране **«Добавьте портфолио»** → кнопка **Добавить**.

Делай **4 проекта** (не 10). На каждый: 2–4 скрина из Telegram + короткий текст ниже.

Скрины: меню → главное действие → результат (заказ / запись / карточка). Без паролей и чужих телефонов — свои тестовые.

---

## Как добавить на Авито

1. Профиль / услуга → **Портфолио** → **Добавить**
2. Название → Описание → фото → сохранить
3. Порядок: сначала **лавка** или **салон** (понятнее обычным клиентам), потом **бани**, потом **сложный учёт**

---

## Проект 1. Лавка / доставка

**Название:**
```
Telegram-бот для лавки: каталог, заказ списком, склад в таблице
```

**Описание:**
```
Бот для овощной/фруктовой лавки.

Клиент открывает каталог или пишет заказ текстом («картошка 3 кг, черри 1»), собирает корзину, подтверждает телефон. Заказ уходит хозяину в Telegram.

Подключена Google Таблица: заказы, продажи, приход, остатки, выручка. Приход и списание хозяин делает командами в боте — строки появляются сами.

Есть повтор прошлого заказа, подсказка про бесплатную доставку, защита от фейковых заявок.
```

**Фото (минимум 3):**
1. Каталог / категории  
2. Заказ списком → «распознал»  
3. Корзина или уведомление хозяину  
4. (по желанию) лист Google «Заказы»

---

## Проект 2. Салон красоты (маникюр)

**Название:**
```
Telegram-бот для салона: запись клиентов и таблица записей
```

**Описание:**
```
Бот для мастера маникюра / салона.

Прайс услуг, расписание и слоты. Мастер сам ставит клиента через бота (имя, телефон, день и время). Заявка приходит в Telegram.

Запись сразу попадает в Google Таблицу: визит, клиент, телефон, услуга, цена, длительность — без переписывания из чата в Excel.
```

**Фото:**
1. Меню / прайс  
2. Расписание со слотами  
3. Подтверждение записи  
4. (по желанию) строка в таблице «Записи»

---

## Проект 3. Каталог / бани

**Название:**
```
Telegram-бот каталог: подбор бани под бюджет
```

**Описание:**
```
Бот-каталог с ценами и подбором под бюджет клиента.

Человек отвечает на пару вопросов (бюджет, параметры) — бот показывает подходящие модели. Можно оставить заявку на расчёт или визит — она уходит владельцу в Telegram.
```

**Фото:**
1. Старт / квиз бюджета  
2. Карточки моделей  
3. Заявка / контакты

---

## Проект 4. Сложный учёт (организация)

**Название:**
```
Telegram-бот со сложным учётом: поиск по большой базе
```

**Описание:**
```
Бот для организации: десятки тысяч карточек, поиск, статусы, несколько сценариев без путаницы.

Документы и материалы можно получить в чат. Бот работает на сервере круглосуточно. Сотрудники ищут нужное в боте, а не листают файлы вручную.

По запросу покажу демо в Telegram.
```

**Фото:**
1. Меню / поиск  
2. Карточка результата  
3. Документ или бланк в чате  

Не выкладывай внутренние секреты организации — только нейтральные демо-скрины.
