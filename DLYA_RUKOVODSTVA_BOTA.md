# Telegram-бот СРО Ассоциации «ГЕН» — кратко для руководства

**Назначение:** круглосуточный помощник для членов СРО, кураторов и сотрудников: поиск организации по ИНН, ответы по типовым вопросам, **официальные бланки** для проверок, контакты (по доступу).

**Сайт остаётся источником истины.** Бот не заменает юристов и не «придумывает» ответы — подтягивает актуальные формы с сайтов СРО и логику, которая на сайте часто размазана по разделам.

---

## Зачем это организации

| Было | Стало с ботом |
|------|----------------|
| Искать бланк на сайте «своего» СРО вручную | После ИНН — выбор СРО (если членств несколько) и кнопки 1–7 |
| Путаница: строительное СРО vs проектное, разные шапки в Word | Отдаётся **комплект именно того СРО**, которое выбрано (ОСОТ — ОСОТ, ОГПО — ОГПО, а не общий шаблон ОГПС) |
| Долгие ответы на одни и те же вопросы | FAQ и ИИ с учётом контекста (не смешиваем строителей и проектировщиков) |
| Реестр ~18 тыс. организаций, 15 СРО | Поиск по ИНН/названию, карточка, плановые проверки из локальных данных |
| Контролёр ищет контакты/реквизиты по разным сайтам | **Одно нажатие:** реестр СРО **или** полная справка по организации (контакты, руководитель, арбитраж и др.) |

**Эффект:** меньше ошибок в пакете документов на контрольную проверку, меньше нагрузки на телефон и почту по типовым вопросам, **единая точка входа** в экосистему из 15 СРО; для контроля — быстрее подготовка к выезду без «гуляния» по чужим сайтам.

## Пример свежей доработки (можно показать на демо)

**Задача:** член может состоять в **нескольких** СРО (например, строительное **ОСОТ** и проектное **СПРОФ**). Бланки с разными реквизитами и названиями ассоциаций. Ошибка в шапке инфолиста или заявления — принципиальный риск на проверке.

**Что сделано (одна рабочая сессия с разработчиком, ориентир — около 1 часа активной работы):**

1. **15 отдельных комплектов бланков** — папки под каждое СРО (ОГПС, МОТС, ОГПП, ОСО, СПРОФ, ПРИИС, ОПП, НОСО, ОСОЕС, ОСОТ, ОСОВС, ОГПО, МГЕО, ГеоИндустрия, ГПС), файлы **скачиваются с официальных сайтов** (раздел «Перечень проверяемых документов»).
2. **Выбор СРО после поиска по ИНН**, если у организации несколько членств или разная деятельность — сначала кнопки «📄 СРО — …», потом меню бланков.
3. **Убрана подмена** «все строители → бланки ОГПС»: ОСОТ получает бланки с nup-sro.ru, ОГПО — с sroogpo.ru и т.д.
4. Скрипты обновления: при смене форм на сайтах — пересобрать карту ссылок и скачать заново (без ручного копирования 105 файлов).

**Для сравнения:** поддержка 15 сайтов «вручную» (найти файл, залить, проверить) — это часы–дни рутины при каждом обновлении; автоматизация через бота и скрипт — **минуты** после настройки.

## Что уже есть в боте (краткий перечень)

- Поиск организации по **ИНН** и названию, карточка по **15 реестрам**
- Скачивание **7 типовых бланков** контроля под выбранное СРО
- Раздел **FAQ** (взносы, НОК, НРС, вступление, проверки и др.)
- **ИИ-помощник** с приоритетом официальных ответов и ссылок на srogen.ru / партнёрские сайты
- Пилот **контекста СРО** для корректных ответов строителям / проектировщикам / изысканиям
- Блок **«Нам доверяют»** — примеры крупных членов с проверкой по ИНН в боте
- Контакты отделов (с ограничением по паролю для внутреннего справочника)
- **Для контролёров:** после поиска организации — выбор «в реестре СРО» или **«полная информация»** (контакты, реквизиты, руководитель, проверки, арбитраж и др. через сервис Checko; справочно, сверять с ЕГРЮЛ)

## Плюс для контроля (формулировка для руководства)

Раньше контролёру часто приходилось **вручную** искать по организации контакты, реквизиты, сведения о руководителе на разных сайтах.  
Сейчас в боте: ввёл ИНН → **одна кнопка** — либо привычная карточка **из реестра СРО** (членство, плановые проверки, бланки), либо **полная справка** по организации. Не заменяет официальную выписку ЕГРЮЛ, но экономит время на подготовке к проверке.

## Ресурсы и риски (честно)

- **Нужен:** один сервер или ПК с запущенным ботом, периодическое обновление реестра (`reestr_sync`), обновление бланков после публикации новых форм на сайтах СРО.
- **Не нужно** держать штат только ради «залить 7 файлов на 15 сайтов» — но **нужны** ответственные за содержание, доступы к сайтам и согласование текстов с юристами.
- ИИ в боте помечен как подсказка; спорные вопросы — телефон Ассоциации и официальный сайт.

## Как показать начальству за 5 минут

1. `/start` в Telegram-боте.
2. Ввести ИНН организации с **двумя** СРО (например, из реестра ФСК «Эверал») — показать **выбор СРО**.
3. Выбрать **ОСОТ** → **Информационный лист** — открыть в LibreOffice/Word: в шапке **ОСОТ**, не ОГПС.
4. Повторить для **СПРОФ** — другой комплект.
5. При желании — вопрос из FAQ или ИИ по взносам/НОК.
6. **Контролёр** (`/controller`): ИНН → «Полная информация» → например **Контакты** — показать, что не нужно отдельно гуглить телефоны.
