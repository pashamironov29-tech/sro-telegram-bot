# Бриф для другого ИИ: СРО-бот — идеи ДЛЯ КОНТРОЛЁРОВ

Скопируй блок ниже другому ИИ целиком.  
Нужны идеи, которыми будут пользоваться **контролёры и аппарат Контрольного комитета**, а не члены СРО (организации).  
Идеи «для членов» (моя организация, бланки члену, взносы) — **не предлагать**, под них уже есть отдельный бриф.

---

## ЗАДАЧА ДЛЯ ИИ

Ты — продуктовый консультант. Нужны **2–5 новых идей** для Telegram-бота СРО под аудиторию **контролёров / КК**.

Критерии хорошей идеи:
1. Решает **боль контролёра** (выезд, подготовка, реестр, документы организации, поле без ПК).
2. Запуск за **1–2 нажатия** или одно сообщение / голос / фото.
3. Не дублирует уже сделанное (см. «Уже есть»).
4. Не заменяет юриста, акт проверки и официальный сайт; ИИ = черновик / подсказка.
5. Реалистично для одного разработчика + VPS + OpenRouter/GigaChat.
6. Пользователь идей — **только контролёр / сотрудник КК** (можно «руководитель КК»), не член СРО.

Формат ответа по каждой идее:
- Название (коротко)
- Кто пользователь (контролёр / сотрудник КК / руководитель аппарата)
- Зачем будут юзать часто (1–2 предложения, без «100%» ради красного слова)
- Как работает в Telegram (шаги)
- На чём опереться из уже сделанного
- Риски / что **не** обещать

Не предлагай: веб-дашборд, CRM «с нуля», соцсеть, игры, MAX как фичу, массовую закачку всех положений без фокуса, «автоматическое исключение из СРО», «бот сам пишет акт проверки и отправляет в суд».

---

## ЧТО ТАКОЕ БОТ (контекст)

Telegram-бот экосистемы **СРО Ассоциаций** (~**15** партнёрских СРО: строительство, проектирование, изыскания и др.). Сайт **srogen.ru** и реестры СРО — **источник истины**. Бот — быстрый вход в рутину, не юрист.

**Контролёр** — сотрудник, который готовит и проводит **контрольные проверки** членов СРО: смотрит реестр, планы по месяцам, бланки, контакты организации, документы (трудовые, уставы, сканы), ездит в регионы / работает удалённо.

**Зачем бот контролёру:** не собирать одно и то же с пяти сайтов и Excel перед выездом; иметь карманный доступ в поле.

**Техника:** Python, Telegram, VPS Москва, кэш реестра ~18 тыс. организаций, ночная синхронизация, ИИ (OpenRouter + запас GigaChat), бланки Word с сайтов СРО. Служебный вход: команда **`/controller`**.

---

## УЖЕ ЕСТЬ ДЛЯ КОНТРОЛЁРОВ (не предлагать как «новое»)

- **`/controller`** — отдельное меню (поиск, НРС, полезная информация, ИИ, документы)
- Поиск организации по **ИНН** / названию по **15 реестрам** → карточка (членство, проверки, статус)
- Развилка: карточка **реестра СРО** или **полная информация** (Checko: контакты, руководитель, арбитраж и др. — справочно)
- **Планы проверок** (месячные) из локальных Word / данных
- Ссылки **НРС** НОСТРОЙ / НОПРИЗ (поиск специалиста)
- **ИИ-помощник:** голос / PDF / Word / фото → черновик разбора (не замена глаз; предупреждение про плохие сканы)
- **Чеклист документов к проверке** + подсказки «что обычно просят» (плановая / жалоба)
- Пилот **DocQA** (ГрК + часть положений) + фолбэк «ответ есть в Положении…»
- FAQ / ИИ с официальными ссылками (общий контур бота)
- Лимиты на платный ИИ (у контролёров выше, чем у обычных)

**Отложено / не начинать без решения Паши:** сверка трудовой/квалсостава с нормами положений («нужно N в НРС»); массовая закачка всех положений; бот в MAX; автозаполнение доверенности.

---

## БОЛИ КОНТРОЛЁРА (отталкивайся от них)

- Перед выездом: ИНН → статус → когда в плане → контакты → бланки — сейчас по кускам, хочется **одним потоком**.
- В поле / удалённый регион: нет папки `kk` и 1С на ноуте — нужен **телефон**.
- Много организаций в месяце: путают, кого уже смотрели, кого отложили, кого «на завтра».
- Сканы трудовых и PDF: ИИ уже есть, но процесс «разбор → что проверить глазами» можно удобнее.
- Исключённые / задвоения ИНН / уже были проверки в этом году — важно не тащить в выезд зря (есть в процессе планов Word, в боте для полевого сценария слабо).
- После проверки: куда делись заметки / черновик / фото с телефона — сейчас легко теряется в чатах.
- Ночной реестр обновляется — «вчера член, сегодня исключён» контролёру важно увидеть **до** выезда.
- Руководитель КК: кто из контролёров что ведёт — в боте почти нет (не обязательно решать сразу).

---

## НАПРАВЛЕНИЯ ДЛЯ ИДЕЙ (зоны, не готовые фичи)

1. **Список «организации к проверке»** у контролёра — без повторного ввода ИНН каждый раз.
2. **Подготовка к выезду за 1 экран** — статус + план + контакты + бланки + чеклист.
3. **Полевой режим** — голос/фото → черновик, быстрые шаблоны фраз, минимум кнопок.
4. **Сигналы по реестру** — исключена / смена статуса / задвоение (для тех, кого контролёр отметил).
5. **Заметки / черновик по ИНН** — личные, не официальный акт.
6. **Связка с месячным планом** — «мой кусок октября», не весь Excel.
7. **Разбор документа** удобнее (трудовая, состав) — **без** обещания сверки с нормами, пока это отложено.

---

## ПРИМЕР СТИЛЯ ПРОДУКТА

Контролёр ввёл ИНН → не смешивать «бланки не того СРО»; официальное — сайт и реестр; ИИ пишет «проверьте глазами».  
Ошибка на выезде (поехали к исключённым) = реальная боль → бот должен бить в такие риски.
