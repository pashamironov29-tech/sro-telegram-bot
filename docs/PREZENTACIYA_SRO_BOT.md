# Официальный Telegram-бот СРО Ассоциации «ГЕН»

**Развёрнутое описание для демонстрации, презентации руководству и партнёрам**

Версия бота: **2026-07-19-v22**  
Официальный сайт: [srogen.ru](https://www.srogen.ru/)

---

## 1. Зачем нужен бот

Сайт Ассоциации содержит полную и актуальную информацию, но у членов СРО, кураторов и вступающих компаний часто один и тот же запрос: **быстро получить ответ или документ**, не обходя десятки разделов и не ждать линии в рабочее время.

Telegram-бот — это **цифровая витрина Ассоциации в мессенджере**:

| Задача | Как решает бот |
|--------|----------------|
| Узнать, когда контрольная проверка у организации | Поиск по **ИНН** или названию → карточка + месяц из **плана проверок** |
| Скачать бланк для проверки или изменений в реестре | Кнопки **7 официальных форм** сразу после карточки организации |
| Найти размер взносов, правила НОК, НРС | **FAQ** + ссылки на сайт + **ИИ-помощник** |
| Позвонить в нужный отдел | **Контакты отделов** (с защитой паролем для внутреннего справочника) |
| Найти партнёрское СРО или НОСТРОЙ / НОПРИЗ | Раздел **Партнёры и НО** с поиском по названию |

Бот **не заменяет** юриста и не даёт индивидуальных консультаций: он **ведёт к официальным материалам** на srogen.ru и снимает рутину с секретariatа и кураторов.

**Ключевая формулировка для клиента:**  
*«Сайт — для изучения и точного расчёта; бот — когда нужен ответ, документ или проверка организации за минуту, без ожидания на линии.»*

## 2. Для кого бот

1. **Действующие члены СРО** — планы проверок, бланки, выписки, изменения в реестре, устранение нарушений, личный кабинет.  
2. **Компании, готовящиеся к вступлению** — взносы, документы, сроки, требования к специалистам, «строительство для себя».  
3. **Кураторы и специалисты** — НОК, НРС, документы в реестр, кураторы НРС.  
4. **Представители в регионах и партнёры** — филиалы, партнёрские СРО, национальные объединения.  
5. **Сотрудники Ассоциации** — меньше однотипных звонков «где бланк» и «когда проверка».

Доступ **круглосуточно** из Telegram на телефоне и ПК.

## 3. Главное меню (четыре опоры)

После команды `/start` пользователь видит клавиатуру из четырёх разделов:

### 🔍 Поиск организации

**Зачем:** единая точка проверки члена СРО по реестру и по **графику контрольных проверок**.

**Как работает:**

- Пользователь вводит **ИНН** (9–12 цифр) или **часть названия** (кавычки не нужны).
- Бот показывает **карточку организации**: членство в одном или нескольких партнёрских СРО, данные с сайтов реестров, при наличии — **месяц плановой проверки** (из официальных файлов планов в папке `plany`).
- Если по названию найдено несколько компаний — список кнопок для выбора (до 10, с подсказкой уточнить запрос).
- К карточке прилагается меню **скачивания документов** (см. раздел 5).

**Техническая основа (для IT):** локальный кэш реестров **15+ партнёрских СРО** (`reestr_sync.py`, `reestr_cache.json`) + планы проверок из Word-таблиц при старте бота.

**Команда:** `/search` — явный режим «только поиск».

---

### ❓ Полезная информация

**Зачем:** структурированная **база знаний** без листания всего сайта.

**Подразделы на первом уровне:**

| Кнопка | Назначение |
|--------|------------|
| **Часто задаваемые вопросы** | Древо тем: вступающим, членам, НОК/НРС, об Ассоциации, филиалы, партнёры, жалобы, благотворительность |
| **Проверяемые документы** | Перечень документов для контрольной проверки + ссылка на сайт |
| **Назад в меню** | Возврат на главную клавиатуру |

**Команда:** `/info` — сразу открывает этот раздел.

---

### 📞 Контакты отделов

**Зачем:** быстрый доступ к **внутреннему телефонному справочнику** отделов Ассоциации.

**Особенность:** раздел может быть **защищён паролем** (настраивается в `config_keys.py`). После успешного ввода пароля доступ запоминается для данного Telegram-пользователя (`contacts_access.json`).

**Зачем пароль:** отделить публичную информацию FAQ от **конфиденциальных** прямых телефонов и внутренних контактов, предназначенных для членов СРО.

---

### 💬 ИИ-помощник

**Зачем:** пользователь пишет вопрос **своими словами** («размер взносов», «нок», «нрс», «план проверок»), бот подбирает **конкретный раздел** на srogen.ru с кнопкой-ссылкой.

**Как устроено:**

1. **Словарь ключевых тем** (НОК, НРС, взносы, выписка, ОДО, бланки и т.д.) — мгновенный ответ без задержки.  
2. **Блок FAQ с сайта «Вопрос-ответ»** — перефразированные формулировки (`voprosy_faq.py`).  
3. При необходимости — **обращение к Groq API** (если ключ задан) для выбора темы из каталога разделов сайта.

**Важно для презентации:** в режиме ИИ-помощника **сначала** обрабатываются темы сайта (чтобы короткие запросы вроде «нок» не превращались в поиск организаций по подстроке в названии), затем — поиск по реестру, если это явно название компании.

**Дисклеймер в боте:** ИИ не заменяет специалиста; точные ответы — на сайте и по телефону **+7 (495) 775-81-11**.

## 6. Умное поведение без лишних кнопок

- **ИНН в любом режиме** — сразу карточка организации (режим ИИ при этом сбрасывается).  
- **Свободный текст** (3+ символа), не похожий на организацию — может уйти в **ИИ-помощник** автоматически.  
- В FAQ при отсутствии совпадения — подсказка и кнопка **«Спросить ИИ-помощника»**.  
- **Навигация:** «меню», `/start`, «назад» — предсказуемый возврат в нужную клавиатуру.  
- **Ошибки:** логирование в `bot_errors.log`, пользователю — вежливое сообщение «попробуйте позже».

## 7. Надёжность и эксплуатация

| Элемент | Описание |
|---------|----------|
| **Многопоточность** | `num_threads=4` — несколько пользователей одновременно |
| **Таймауты Telegram API** | Увеличенные connect/read timeout |
| **Секреты** | Токен бота, Groq, пароль контактов — в `config_keys.py`, не в коде |
| **Обновление реестра** | Скрипт `reestr_sync.py` → `reestr_cache.json` |
| **Планы проверок** | Word-файлы в `plany/` — подхватываются при запуске |
| **VPS** | Готовы `docs/VPS_SETUP.md`, `vps/install.sh`, systemd-сервис — перенос «24/7 на сервер» |

**Запуск на Windows (офис / демо):** `START_BOT.bat` / `STOP_BOT.bat` — один процесс на один токен BotFather.

## 8. Сценарий демонстрации (5–7 минут)

1. **`/start`** — приветствие, обзор возможностей.  
2. **ИНН известной организации** — карточка, СРО, месяц проверки, кнопка «Информационный лист».  
3. **Поиск по части названия** — выбор из списка.  
4. **❓ Полезная информация → Действующим → Расписание проверок** — кнопки на сайт и план.  
5. **🎓 Специалисты и НОК → Правила НОК** или **💬 ИИ-помощник → «нок» / «нрс»** — ссылка на раздел сайта.  
6. **🤝 Партнёры → текст «нострой»** — быстрый ответ с URL.  
7. **📞 Контакты** — показать, что без пароля доступ ограничен (если включена защита).  
8. **`/help`** — команды для опытных пользователей.
