# Бриф для другого ИИ: СРО-бот — что это и какие фичи «будут юзать 100%»

Скопируй блок ниже другому ИИ целиком. Он должен предложить **новые идеи**, а не пересказывать уже сделанное.

---

## ЗАДАЧА ДЛЯ ИИ

Ты — продуктовый консультант. Нужны **2–5 новых идей** для Telegram-бота СРО, которыми люди **реально будут пользоваться каждый день / каждую неделю**, а не «вау раз и забыли».

Критерии хорошей идеи:
1. Решает **боль, которая уже есть** (звонки, поиск по сайтам, забытые сроки, ошибки в бланках).
2. Запуск за **1–2 нажатия** или одно сообщение.
3. Не дублирует уже сделанное (см. ниже «Уже есть»).
4. Не требует юриста внутри бота и не заменяет официальный сайт.
5. Реалистично для одного разработчика + VPS + OpenRouter/GigaChat.

Формат ответа:
- Название идеи (коротко)
- Кто пользователь (член СРО / контролёр / сотрудник аппарата / вступающий)
- Зачем «100% будут юзать» (1–2 предложения)
- Как работает в Telegram (шаги)
- Что уже есть в боте, на чём опереться
- Риски / что **не** обещать

Не предлагай: «красивый UI», «дашборд в веб», «соцсеть», «игры». Не предлагай MAX/новый мессенджер как фичу (это отдельный канал). Не предлагай массовую закачку всех положений с сайтов без фокуса.

---

## ЧТО ТАКОЕ БОТ (контекст)

**Название/контекст:** Telegram-бот для экосистемы **СРО Ассоциаций** (около **15 партнёрских СРО**: строительство, проектирование, изыскания и др.). Официальный сайт ассоциации — **srogen.ru**. Сайт и реестры СРО — **источник истины**; бот — удобный вход, не юрист.

**Кто пользуется:**
- **Члены СРО** (организации) — бланки, FAQ, «когда проверка», типовые вопросы.
- **Контролёры / аппарат Контрольного комитета** — реестр, планы, подготовка к проверке, ИИ по документам.
- **Сотрудники** — быстрые справки, меньше звонков «куда бланк / какой ИНН».
- **Вступающие** (частично) — FAQ про вступление, взносы, НРС/НОК.

**Зачем бот существует (одной фразой):**  
Убрать рутину «погулять по 15 сайтам и найти бланк/статус/ответ» — всё в Telegram за минуту.

**Техника (кратко):** Python, Telegram, VPS в Москве, кэш реестра ~18 тыс. организаций, ночная синхронизация, ИИ через OpenRouter (+ запас GigaChat), бланки Word с сайтов СРО.

## УЖЕ ЕСТЬ (не предлагать как «новое»)

- Поиск организации по **ИНН** / названию → карточка по **15 реестрам**
- **Планы проверок**, статус членства / исключена
- Скачивание **бланков** под выбранное СРО (если у орг. несколько СРО — выбор)
- **FAQ** + **ИИ** с ссылками на официальные разделы сайта
- Автозаполнение части бланков из открытых данных реестра (инфолист, заявление на проверку; доверенность — выключено)
- Опрос для инфолиста (пилот)
- Для контролёров: **`/controller`** — голос / PDF / Word / фото → ИИ-помощник (черновик, не замена глаз)
- Пилот **DocQA** по ГрК и части положений (админ) + фолбэк «ответ есть в Положении…»
- Полная справка по организации (Checko) для контролёров
- Лимиты на платный ИИ; FAQ/ИНН без лимита

**Отложено / не начинать без решения:** бот в MAX; сверка трудовой с нормами положений «нужно N в НРС»; массовая закачка всех положений; меню «важные документы» для всех (сейчас пилот).

## БОЛИ ЦЕЛЕВОЙ АУДИТОРИИ (отталкивайся от них)

- «Когда у нас проверка и что готовить?» — забывают, ищут в Excel/почте.
- «Какой бланк качать и для какого СРО?» — путают ОГПС/ОСОТ/проектное.
- «Мы ещё члены или уже исключили?» — смотрят раз в год, узнают поздно.
- Контролёр: перед выездом собирает пакет с 5 сайтов + своя база.
- Одни и те же вопросы в секретариат: взносы, НРС, НОК, куда слать документы.
- После проверки: что делать с предписанием / сроками (сейчас слабо закрыто ботом).
- Удалённые регионы / отпуск: нужен быстрый доступ без ПК с папкой kk.

## НАПРАВЛЕНИЯ, ГДЕ ИДЕИ «100% юза» особенно желанны

(не готовые фичи — зоны для твоих предложений)

1. **Напоминания и дедлайны** (проверка, взносы, срок ответа на запрос) — push в Telegram.
2. **«Моя организация»** — один раз привязал ИНН, дальше всё без повторного поиска.
3. **Чеклист перед проверкой** — персональный список «что сдать» по статусу/СРО.
4. **Статус заявки / обращения** без звонка (если есть каналы у аппарата).
5. **Микро-фичи для контролёров в поле** (выезд) — быстро, офлайн-ощущение, голос.
6. **Снижение звонков секретарю** — одна кнопка на самый частый сценарий недели.

## ПРИМЕР УЖЕ УДАЧНОЙ ЛОГИКИ (чтобы понять стиль продукта)

Член в двух СРО → бот не отдаёт «чужой» бланк: сначала выбор СРО, потом комплект именно этого СРО.  
Ошибка в шапке Word на проверке = реальный риск → бот бьёт в эту боль.

ИИ помечен как подсказка; спорное — на сайт и телефон ассоциации.
