# Контролёры: личные графики Excel + куда развивать бота

**Сохранено:** 25.08.2026  
**От чего отталкиваемся:** каждому контролёру делают персональный график проверок (Excel на Desktop).

## Примеры файлов

- `Desktop\Маштаков О.Ю. (сентябрь).xlsx` — месяц целиком, без разбивки по дням  
- `Desktop\Зеленский И.А. (21-24.09.2026г.).xlsx` — кусок дат (пн–чт) + пометки по уведомлениям

## Что внутри графика (структура)

Шапка: «График проведения контрольных проверок…» + перечень СРО + **ФИО члена КК**.

По каждой организации обычно **две строки**:

| Поле | Пример |
|------|--------|
| Форма + название | ООО «НПО МАРС» |
| Адрес | город, улица… |
| Руководитель | ФИО |
| **ИНН** | 7445039069 |
| Рег. № + **СРО** | 382 (ОГПО) |
| Телефоны | 8-906-… |
| Заметки (у Зеленского) | «13.08 отпр.ув.», перенос, метро, «из списка Петрова» |

Одна фирма может быть **дважды** (разные СРО: ОГПО + ГеоИндустрия и т.п.) — как в боте при нескольких членствах.

## Боль / как живут сейчас

1. График собирают **вручную** (или полуручную) под контролёра.  
2. Перед звонком/письмом смотрят Excel: адрес, телефон, ИНН, какое СРО.  
3. Чтобы **проверить актуальность** (ещё член? исключили?) — идут на сайты / реестры = вкладки.  
4. Пометки («уведомление отправлено», перенос) живут **в ячейках Excel**, не в боте.

## Что уже хорошо в боте (офис)

**Один ИНН → сразу картина по 15 СРО + при желании Checko** — вместо кучи вкладок. Это ядро для офисного контролёра. От этого и пляшем.

---

## Что можно сделать с этими графиками (идеи по ценности)

### 1. Загрузить график контролёра в бота (высокий приоритет)
Файл Excel → бот понимает ИНН / названия / СРО / телефоны.  
В `/controller`: **«Мой график»** — список на месяц или на даты.  
Тап по строке → **сводка по ИНН** (реестр 15 СРО + Checko), без ручного поиска.

*Офисная польза:* график уже есть; бот не заменяет Excel при сборке, а делает каждую строку «живой» за 15 сек.

### 2. Прогон графика по свежему реестру (высокий)
Кнопка **«Проверить мой график»** → по всем ИНН из файла:  
исключена / не член / задвоение / есть проверки в 2026.  
Красным — «перепроверь до выезда/звонка».

*Офисная польза:* то, что Паша делает скриптом к месячным планам Word — но **на персональном списке контролёра**.

### 3. Обогатить строку перед звонком (средний)
Из графика открыл ИНН → рядом: актуальный статус, контакты Checko, бланки этого СРО, чеклист.  
Не «выездной пакет в поле», а **«карточка к звонку за 20 сек»**.

### 4. Не вести второй Excel в боте (пока не просят)
Статусы «сделал / отложил» и «отпр.ув.» контролёры уже пишут в файле.  
Дублировать это в Telegram = конкуренция с Excel. Имеет смысл только если сами попросят.

### 5. Сборка графика ботом (низкий / позже)
«Собрать график Маштакову на сентябрь из общего плана» — отдельный большой кусок (кто назначает, откуда адреса/телефоны). Сейчас источник — их процесс, не бот.

## Связь с прошлыми идеями (переоценка)

| Было | Для офиса + графиков |
|------|----------------------|
| Выездной пакет | Слабее; вместо него — **карточка к строке графика** |
| Мой кусок месяца руками | Слабее, если график уже делают в Excel → **импорт файла** |
| Сигнал «не ехать» | Сильно, если привязан к ИНН из **загруженного графика** |
| Заметки / выписка трудовой | Ок как дополнение, не ядро |
| Моя организация (член) | Другой контур (DEMO для членов) — не путать |

---

## Практичный порядок

1. Зафиксировать формат Excel (два примера выше) — **сделано**.  
2. Демо: загрузка xlsx контролёра → список ИНН в боте.  
3. Тап → сводка «один ИНН / 15 СРО + Checko».  
4. Кнопка «прогнать список по реестру» (исключённые и т.п.).  
5. Потом — утренние сигналы только по ИНН из графика.
